# Publisher-selected media topic pathways

## Implementation checkpoint

September 28, 2026 UTC. The reviewed base is
`eefde4963887fe1413e8568e47555ee6fb33c694`, including the tested Scripture-search
source. This feature extends the existing publisher topic array and authorized
catalog search. It adds no schema, API, provider, dependency or personal-interest
record. Integration and verified-live acceptance remain separate.

Publishers may deliberately add Grief, Hope, Marriage or Prayer from optional
editorial prompts, or enter their own ordinary labels. The existing twelve-topic
and forty-character bounds remain authoritative. Selected labels do not imply a
diagnosis, personal condition, theological endorsement or a viewer preference.
There is no automatic tagging, sensitive inference or default opt-in.

The suggestions use the existing dirty-field and rights-review path. Already
selected suggestions and a full topic list disable further additions. Current
in-flight or uncertain commands disable the entire editor fieldset, including
the new controls. Removing a label remains an explicit edit to the topic text.

Readable library cards and recording details expose the publisher's actual labels
as topic links. The library also offers the four optional browsing entry points,
clearly identified as recording topics. Selecting a topic starts a fresh search,
clearing other filters and pagination. Labels are URL-encoded; there is no provider
fetch, recommendation service or background link prefetch.

The search URL now owns the library's applied keyword, format, speaker, series,
topic, Scripture-system and Scripture-passage filters and result page. Controls
show those actual values, with an applied-filter summary and a clear action.
Reload and browser Back restore the same search. Submitting filters returns to
page one; page navigation preserves the active filters. Existing publishing-studio
pagination remains local. Enlarged pagination wraps without splitting button words.

## Access and privacy

No service predicate or projection changed. The canonical catalog still applies
current publication, rights, owner eligibility, church membership, blocks and
audience before records and totals. Hidden source labels never enter public cards;
guessing a private label supplies no otherwise-inaccessible result. The new links
use only the already-permitted topic projection.

Foreground/offline/session revalidation conceals source cards, titles and labels
under the existing reader boundary. The chosen query remains a deliberate local
browsing URL, not a stored private-interest setting or activity assessment. Sharing
that URL shares its filters, not source access. The feature creates no notification,
profile update, church grant, media rights assertion or provider contact by browsing.

when checking saved content; the fixture now opens the canonical saved editor.

No migration is introduced. The reviewed runtime expects its existing Scripture
and playlist base migrations; release integration owns those prerequisites and
the corresponding recovery artifacts. No production migration, deployment or
operator/provider/policy activation is performed by this feature checkpoint.
