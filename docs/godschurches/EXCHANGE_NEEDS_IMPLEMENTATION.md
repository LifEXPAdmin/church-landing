# Church Needs implementation and verification

18 September 2026 UTC. Local verification is in progress. Production still serves
2026.09.18.1; the pending Needs migration and release are not deployed.

## Delivered behavior awaiting release

Existing church-owned Exchange listings provide typed Donate, Sell to us,
Transport and Volunteer slots. Coordinator consent and current church duties
govern private offers. Atomic whole quantities distinguish promises, actual
receipts and equipment returns. Paid quotes reserve capacity only after explicit
acceptance and do not process payment or create tax receipts. Timed help reuses
the existing event role and signup capacity.

The feature includes organizer setup, listing publication, contributor and
organizer history, exact lost-response recovery, partial receipts and corrections,
equipment loan terms and returns, private selected-evidence reports, organizer
updates, deadlines, honest partial closing and repeat drafts. Repeat preserves
structure, with fresh dates, coordinator consent and event-role selection.
Existing authorized church Need posts can link the same canonical slots.
Settings, Help, privacy/terms explanations and release guidance are included.

Current source, bilateral block, audience, consent and duty epochs protect every
read and mutation. Separate retained pickers recheck publishing and volunteer
scope on resume. Account exports contain the owner's contributions; erasure
removes private text and attribution while retaining opaque fulfillment totals.
Protected restoration quarantines recovered contributions and consent. Existing
notification fanout and consumer deliver current-contributor updates; phone
alerts require their separate dated opt-in.

## Runtime review

The maximum twelve-slot public projection uses nineteen SELECTs. A bounded
twenty-contributor page initially used 359 SELECTs. Reusing participant inputs
and identical canonical listing predicates within the read transaction reduces
that fixture to 48 SELECTs. All six before/after projection hashes match,
including exact private fields and ordering; the second page contains the
twenty-first row. Median local contributor read time changes from about 140ms
to 28ms. This is isolated local evidence, not a production latency claim.
The mutation permission path is unchanged. Fresh permission comparisons cover
quotes, contact restrictions, bilateral blocks, moderation, membership versions,
revoked/regranted duties and suspended contributors. No cross-request permission
cache, dependency, worker or duplicate volunteer ledger is introduced.

Route-manifest accounting finds twelve Needs detail/history chunks totaling
625,371 uncompressed bytes and about 184,235 gzip bytes. Two additional chunks
beyond the existing listing total 25,991 raw and about 6,816 gzip bytes. These
numbers exclude shared layouts, styles, images and response headers; no bundle
size improvement is claimed. Test tooling stays outside application bundles.
